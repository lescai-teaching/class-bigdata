Pro Tip: Ensure scripts have the #!/usr/bin/env Rscript shebang.

4. Per-Experiment Modules

Wrap analysis scripts in a process block. Use metadata tuples.

modules/mean_sd/main.nf
process MEAN_SD {
    tag "$name"
    input:
    tuple val(name), path(data)
    output:
    tuple val(name), path("${name}_meansd.tsv"), emit: meansd
    script:
    "mean_sd.R $data $name"
}

5. Summary Module

The SUMMARY process waits for a collection of files.

modules/summary/main.nf
process SUMMARY {
    input:
    path stats_files
    output:
    path "all_experiments_summary.tsv"
    script:
    "generate_final_summary.R"
}

6. Assembly (main.nf)

Use collect() to bridge the gap between parallel steps and the final summary.

workflow {
    input_ch = channel.fromPath(params.input)
        .splitCsv(header:true, sep:'\t')
        .map { [it.experiment, it.datafile] }

    MEAN_SD(input_ch)
    PC1_LOADING(input_ch)
    MAD(input_ch)

    all_stats = MEAN_SD.out.meansd.collect { it[1] }
        .combine(PC1_LOADING.out.pc1load.collect { it[1] })
        .combine(MAD.out.mad.collect { it[1] })

    SUMMARY(all_stats)
}

7. Execution

Run with the desktop profile to use Docker/local execution.

nextflow run main.nf -profile desktop
